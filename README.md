# Pink Petals Parlour 🌸

A responsive beauty parlour website built using HTML, CSS, and JavaScript, with Firebase Firestore integration for appointment booking.

## Features
- Responsive design for desktop and mobile devices
- Home, Services, About, and Contact sections
- Appointment booking form
- Form validation
- Firebase Firestore integration to save appointment requests
- Booking time validation (10:00 AM – 8:00 PM)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase Firestore

## Project Purpose
This project was developed as a frontend portfolio project to demonstrate web development skills, responsive design, JavaScript functionality, and basic Firebase integration.
